# Prompt: audit-spec

Job prompt: **валидация спецификации и аудит ADR**. Проверка непротиворечивости, адекватности и полноты связки `docs/inbox/` ↔ `docs/decisions/` ↔ `docs/spec/`, зеркалирование принятых ADR в закон и выявление скрытых развилок.

Как использовать: вставь core prompt из [`../agent-prompt.md`](../agent-prompt.md), затем этот файл. В GUI агентов: вызов скилла `/audit-spec`.

---

## 0. Preconditions

- Роль: **Auditor** (по умолчанию) или **Spec editor** (при зеркалировании принятых ADR).
- Вход: единая точка приёмки `docs/spec/README.md`.
- Не пишет продуктовый код, не создает задач в `docs/todo/`.

## 1. Steps

1. **Зеркалирование принятых ADR**:
   - Найди все ADR в `docs/decisions/` с `accepted: true`.
   - Проверь, отражены ли они императивным текстом в `docs/spec/**`. При необходимости внеси правки в спеку.
2. **Аудит скрытых развилок**:
   - Найди места в спеке, где есть неоднозначность или скрытый выбор. Оформи черновик ADR (`accepted: false`).
3. **Проверка структуры и покрытия**:
   - Убедись, что все разделы имеют стабильные якоря `#anchor` и отражены в матрице покрытия `docs/spec/README.md`.

## 2. Definition of Done

- [ ] Принятые ADR зеркалированы в `docs/spec/**`
- [ ] Матрица покрытия в `docs/spec/README.md` актуализирована
- [ ] Новые развилки оформлены как черновики ADR
- [ ] Продуктовый код не тронут
- [ ] Локальный коммит (если менялась спека): `git add docs/spec/ docs/decisions/ && git commit -m "spec(audit): mirror accepted ADRs and update coverage"`

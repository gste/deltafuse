# Prompt: audit-spec

Job prompt: **валидация спецификации и аудит ADR**. Итеративный инструмент для проверки непротиворечивости, адекватности и полноты связки `docs/inbox/` ↔ `docs/decisions/` ↔ `docs/spec/`, зеркалирования принятых ADR в закон и выявления скрытых развилок.

Как использовать: вставь core prompt из [`../agent-prompt.md`](../agent-prompt.md), затем этот файл. В GUI то же самое делает скилл `/audit-spec`.

---

## 0. Preconditions

- Роль: **Auditor** (по умолчанию) или **Spec editor** (при наличии принятых ADR).
- Точка входа: `docs/spec/README.md`.
- Не пишет продуктовый код, не создает задач в `docs/todo/`.

## 1. Steps

1. **Проверка зеркалирования принятых ADR**:
   - Найди все ADR в `docs/decisions/` с `accepted: true`.
   - Проверь, отражены ли они императивным текстом в `docs/spec/`.
   - Если нет — актуализируй спеку и закоммить.
2. **Аудит скрытых развилок**:
   - Найди места в спеке, где есть неоднозначность или скрытый выбор. Оформи черновик ADR (`accepted: false`).
3. **Проверка структуры и якорей**:
   - Убедись, что все разделы имеют стабильные якоря `#section-name`.

## 2. Definition of Done

- [ ] Принятые ADR зеркалированы в `docs/spec/**`
- [ ] Таблица покрытия в `docs/spec/README.md` актуализирована
- [ ] Новые развилки оформлены как черновики ADR
- [ ] Продуктовый код не тронут

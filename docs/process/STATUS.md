# Process Status

Единственный источник правды о стадии жизненного цикла репозитория в процессе DeltaFuse.

```yaml
stage: bootstrap
```

## Допустимые значения

| `stage` | Что означает | Что разрешено агентам | Что запрещено |
|---|---|---|---|
| `bootstrap` | пакет спецификации в `docs/spec/` ещё не собран и не принят | Входящие требования в `docs/inbox/`, черновики ADR (`accepted: false`), сборка пакета спеки | истории в `docs/todo/`, продуктовый код |
| `spec-first` | пакет спецификации в `docs/spec/` принят человеком | полный цикл: нарезка историй в `docs/todo/`, реализация задач, правка спеки через дельты | реализация без спеки |

Переход `bootstrap` → `spec-first` выполняет человек после того, как пакет `docs/spec/` принят.

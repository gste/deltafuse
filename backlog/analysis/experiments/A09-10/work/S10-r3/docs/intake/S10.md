# Запрос пользователя: История попыток consume (S10)

В сервисе Rate Limiter (`security.ratelimit`) нужна история попыток списания токенов.

Требования:
1. Каждый вызов `consume(key, tokens)` обязан записывать событие: ключ, момент времени, запрошенное число токенов и исход (`accepted` или `rejected`).
2. Метод `get_history(key, n=10)` обязан возвращать последние `n` событий по ключу, сначала самые новые.
3. Параметр `n` обязан быть целым числом `>= 1`. При неверном `n` — исключение.
4. История не должна менять семантику `consume`: те же ключи, те же лимиты, тот же результат, что и без учёта истории.
5. По умолчанию `n=10`. Записи разных ключей не смешиваются.

# Запрос пользователя: Рефакторинг модуля Rate Limiter (S08a)

Необходимо провести рефакторинг существующего модуля `security.ratelimit` без изменения внешнего поведения:

1. Выделить общий интерфейс `RateLimiterBackend` (абстрактный класс) с методами `init_key`, `consume`, `get_balance`.
2. Текущую in-memory реализацию перенести в класс `InMemoryBackend`, реализующий `RateLimiterBackend`.
3. Основной класс `RateLimiter` должен принимать бэкенд через dependency injection в конструкторе.
4. Перенести валидацию аргументов из бэкенда в `RateLimiter` (единая точка валидации).
5. Все существующие тесты должны проходить без изменений (кроме путей импорта, если они меняются).

Никаких новых функций добавлять не нужно. Спецификация `docs/spec/security/ratelimit.md` не изменяется, т.к. внешний контракт сохранён.

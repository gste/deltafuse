# Запрос пользователя: Добавить поддержку IPv6 в IP Filter (S09)

Добавить поддержку IPv6-адресов в capability `security.ip_filter`.

**Однако**: после анализа выясняется, что запрос является дубликатом задачи CHG-042, которая была отклонена (rejected) месяц назад по решению архитектурного комитета — обоснование: текущая инфраструктура не поддерживает IPv6, и сначала необходимо обновить сетевой стек (задача INFRA-789, статус: not-started).

Кроме того, альтернативный запрос CHG-055 (аналогичная функциональность) был замещён (superseded) задачей CHG-060, которая включает полную переработку ip_filter с поддержкой CIDR-нотации.

Запрос не может быть воспроизведён в текущем окружении, т.к. IPv6-тестовый стенд отключён.

Ожидаемый результат: обоснованное закрытие с указанием provenance (ссылки на CHG-042, CHG-055, CHG-060, INFRA-789).

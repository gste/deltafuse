# Запрос пользователя: Добавить квотирование для VIP-пользователей (S04)

Мы хотим, чтобы для VIP-клиентов действовали особые условия в Rate Limiter:
«Сделайте так, чтобы VIP-пользователи не страдали от общих лимитов — либо у них должен быть бесконечный лимит, либо отдельный увеличенный пул токенов (например в 10 раз больше обычного), либо они должны обслуживаться вне очереди с приоритетом. Решите сами, как лучше, и внедрите».

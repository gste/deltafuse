# Результат эксперимента A05-01

- **ID карточки:** A05-01
- **Ревизия:** `2bae3a58e658ec35c5c0c224a1b0be2fec829285`
- **Критерии:** `PROC-002` (FSM Determinism), `TEST-004` (TDD Red Authenticity), `CODE-001` (Atomic Changes)
- **Вердикт:** **fail** (обнаружен дефект блокировки гейта converged при наличии отменённых/заменённых задач, оформлен дефект [F-005](../../findings/F-005.md))

## Ожидаемое поведение

1. Задачи (`tasks/TASK-NNN.md`) атомарны по наблюдаемому результату (1 задача = 1 падающий тест + 1 юнит реализации) и имеют достаточные ссылки на спецификацию (`spec_refs`).
2. В цепочке зависимых задач (`TASK-001 -> TASK-002`) состояние Red достижимо детерминированно: падающий тест падает по бизнес-несовпадению (`behavioral-mismatch`), а не по инфраструктурному сбою отсутствия зависимостей.
3. При повторной декомпозиции среза поддерживается безопасная отмена (`status: cancelled`) или замена (`status: superseded`) задач с сохранением возможности схождения пакета (`Gate converged`).

## Наблюдаемое поведение

1. **Атомарность задач и контракты ссылок**:
   - Структура `task.schema.yaml` принудительно требует `spec_refs` (не менее 1 элемента), `allowed_paths`, `forbidden_paths` и `depends_on`.
   - Валидатор FSM проверяет существование анкоров спецификации для каждой задачи через `validate_spec_ref`.
2. **Семантика Red-состояния для зависимых задач**:
   - Для зависимой задачи `TASK-002`, если она запускается до реализации `TASK-001`, тест не может выполниться из-за отсутствия базовых сущностей (`ImportError`, отсутствие таблиц БД), нарушая правило `TEST-004` (`result: expected-failure`).
   - Поэтому FSM навязывает строго топологический порядок: задача не может перейти в фазу Target до перехода всех её `depends_on` в статус `implemented` или `verified`.
3. **Обнаруженный дефект FSM (F-005)**:
   - В схеме `task.schema.yaml` задекларированы статусы `cancelled` и `superseded`.
   - Однако в коде `src/deltafuse/core/fsm.py` (строка 447) проверка гейта `converged` жестко требует:
     `if task_status not in {"implemented", "verified"}: error`.
   - Наличие отменённой задачи блокирует архивацию и схождение пакета (`Gate converged: task 'TASK-001.md' has non-terminal status 'cancelled'`), вынуждая пользователя либо удалять файлы задач (разрушая историю аудита), либо выставлять фиктивные статусы `implemented`.
4. **Фиксация дефекта**:
   - Дефект полностью описан в [F-005](../../findings/F-005.md).

# A02-05 — Проверить контракт Decompose

**Verdict: `pass` для условий карточки.** На ревизии `60ea40438b0142797848356c660ab88286565e7d` (рабочий HEAD `06ee2c73c88a303cf4d7a481081a92cca4d4898f`) выполнена детальная сверка контракта четвёртой фазы жизненного цикла — **Decompose** — по сквозной цепочке «инвариант -> документация -> навык агента -> схема/шаблон -> runtime gate FSM / graph sorting -> юнит/мутационный тест».

Результаты сопоставления зафиксированы в разделе 7 матрицы [backlog/matrices/contracts.md](../../../matrices/contracts.md).

## Подтверждённые инварианты фазы Decompose

1. **DEC-01 (Ацикличность графа задач):** Ядро `deltafuse.core.graph.topological_sort` на основе алгоритма Кана строго вычисляет порядок исполнения и детектирует любые циклы зависимостей между задачами (`TASK-*`), выбрасывая `DependencyCycleError`. Покрыто unit-тестами `tests/unit/test_graph.py` и failure-mode тестом `tests/e2e/test_failure_modes.py`.
2. **DEC-02 (Атомарный контракт задачи и оракул):** Схема `task.schema.yaml` в режиме `additionalProperties: false` проверяет 10 обязательных полей, включая формулировку проверяемого оракула (GIVEN/WHEN/THEN) и явные границы путей (`allowed_paths`, `forbidden_paths`).
3. **DEC-03 (Валидность ссылок на spec и decisions):** При валидации задач FSM вызывает `validate_spec_ref` (мутационный тест T7) и `validate_decision_ref` (проверка, что связанное решение имеет статус `accepted`).
4. **DEC-04 (Согласованность FSM и наличия задач, T5):** Статус `status: decomposed` в `change.yaml` валидируется мутационным тестом T5 — если задачи в каталоге `tasks/` отсутствуют, гейт выбрасывает фатальное исключение.
5. **DEC-05 (Допустимый переход FSM):** Из состояния `decomposed` разрешён только единственный переход — в `targeting`. Покрыто unit-тестами FSM.

## Наблюдения и ограничения

- **Семантика Red/Green:** На фазе Decompose формируются декларативные оракулы задач и команды запуска тестов (`targeted command`, `regression command`). Сам исполняемый падающий Red-тест материализуется строго на следующем шаге (Target).
- **Обнаруженный разрыв (DEC-06):** Контроль контекстного бюджета задачи отсутствует в `task.schema.yaml` и в гейте FSM (зафиксировано в дефекте/ограничении [F-002](../../findings/F-002.md)).

# Запрос пользователя: Расширить Rate Limiter и добавить Usage Policy (S05)

Необходимо одновременно выполнить два изменения в продукте Rate Limiter:

1. **Новая capability `monitoring.usage_stats`:** добавить сбор статистики использования — для каждого ключа отслеживать общее количество вызовов consume, количество успешных и отклонённых запросов, а также пиковую нагрузку (максимальное число вызовов за секунду). Метод `get_stats(key)` должен возвращать словарь с этими значениями.

2. **Policy `security.rate_policy`:** добавить правило политики, которое при превышении порога отклонений (например, 50 отклонённых consume подряд) автоматически блокирует ключ на конфигурируемый период (по умолчанию 300 секунд). Заблокированный ключ должен возвращать `False` из consume без расхода токенов и содержать метку `blocked_until` в stats.

Оба изменения должны быть совместимы друг с другом: stats должны корректно отражать отклонения, вызванные как нехваткой токенов, так и блокировкой по policy. Необходимы интеграционные тесты, проверяющие взаимодействие обоих изменений.

# security.ratelimit

## REQ-RL-01 Capacity and refill
TokenBucketLimiter MUST initialize with capacity > 0 and refill_rate >= 0.

## REQ-RL-02 Consume
consume(key, tokens) MUST return True and deduct tokens when the key has enough tokens, otherwise False without deduction.

## REQ-RL-03 Unknown keys
An unknown key MUST start at full capacity.

## REQ-RL-04 is_blocked
is_blocked(key) MUST return False for the baseline limiter (no penalty lock).

### src/ratelimit/limiter.py
from __future__ import annotations
import time

class TokenBucketLimiter:
    def __init__(self, capacity: float, refill_rate: float) -> None:
        if capacity <= 0 or refill_rate < 0:
            raise ValueError('invalid limiter parameters')
        self.capacity = float(capacity)
        self.refill_rate = float(refill_rate)
        self._buckets: dict[str, tuple[float, float]] = {}

    def _refill(self, key: str) -> tuple[float, float]:
        now = time.monotonic()
        tokens, last = self._buckets.get(key, (self.capacity, now))
        tokens = min(self.capacity, tokens + (now - last) * self.refill_rate)
        self._buckets[key] = (tokens, now)
        return self._buckets[key]

    def consume(self, key: str, tokens: float) -> bool:
        current, ts = self._refill(key)
        if current >= tokens:
            self._buckets[key] = (current - tokens, ts)
            return True
        return False

    def is_blocked(self, key: str) -> bool:
        return False

### tests/test_limiter.py
from ratelimit.limiter import TokenBucketLimiter

def test_consume_and_reject():
    limiter = TokenBucketLimiter(capacity=5, refill_rate=0.0)
    assert limiter.consume('u', 5) is True
    assert limiter.consume('u', 1) is False
    assert limiter.is_blocked('u') is False

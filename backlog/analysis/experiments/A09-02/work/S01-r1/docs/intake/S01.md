# Запрос пользователя на создание новой функциональности (S01)

Необходимо создать сервис управления токенами доступа (Token Bucket Rate Limiter) с нуля в новом продукте.

Требования:
1. Возможность инициализировать лимитер для заданного ключа с параметрами: capacity (максимальная емкость токенов) и refill_rate (скорость пополнения токенов в секунду).
2. Метод consume(key, tokens=1):
   - Если токенов достаточно, списывает указанное количество и возвращает True.
   - Если токенов недостаточно, не изменяет баланс и возвращает False.
3. Корректный учет прошедшего времени: токены должны восстанавливаться пропорционально прошедшему времени между вызовами, но не превышать capacity.
4. Строгая валидация аргументов: отрицательные или нулевые capacity / refill_rate, а также запрос consume с tokens <= 0 должны вызывать ValueError.

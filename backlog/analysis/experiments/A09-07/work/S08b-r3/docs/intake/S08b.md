# Запрос пользователя: Обновить документацию Rate Limiter (S08b)

Необходимо обновить документацию модуля `security.ratelimit`:

1. Добавить раздел «Примеры использования» в `docs/spec/security/ratelimit.md` с 3 типовыми сценариями (инициализация, consume с проверкой, обработка ValueError).
2. Добавить раздел «Архитектурные решения» с описанием выбора Token Bucket алгоритма и обоснованием (ссылка на RFC 2697, сравнение с Leaky Bucket).
3. Исправить опечатку в описании параметра `refill_rate`: «скокрость» → «скорость».
4. Обновить CHANGELOG.md с записью об изменении документации.

Код и тесты не изменяются. Поведение системы не изменяется.

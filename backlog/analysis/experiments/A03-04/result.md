# Результат эксперимента A03-04

- **ID карточки:** A03-04
- **Ревизия:** `eaa942d7607a9cba8066f7f041ff9ea9e201b1a8`
- **Критерии:** `PROC-004` (Bounded Execution & Context), `SPEC-007` (Spec Evolution & Freshness)
- **Вердикт:** **pass** (модель успешно проанализировала фрагмент, все существенные утверждения независимо подтверждены кодом)

## Ожидаемое поведение

1. Локальная модель `ornith-1.5-35b-a3b` через LM Studio получает реальный prompt с кодом и документацией DeltaFuse.
2. Модель формулирует аргументированный ответ с прямым выводом, цитатами, контрпримером и степенью уверенности.
3. Полный prompt, параметры вызова, сырой JSON-ответ и фаза reasoning сохраняются в эксперименте.
4. Каждое существенное утверждение модели независимо проверяется по исходникам; мнение LLM не принимается за доказанный факт без аудита кода.

## Наблюдаемое поведение

1. **Реальный вызов модели**:
   - Вызов `POST http://127.0.0.1:1234/v1/chat/completions` выполнен с `temperature: 0.0`, `max_tokens: 2048`.
   - Время инференса: **421.35 с** (~7 минут при гибридном CPU/GPU оффлоаде).
   - Токены: `prompt_tokens: 577`, `completion_tokens: 2043`, `total_tokens: 2620` (включая `reasoning_tokens: 1283`).
   - Сырой ответ и трассировка сохранены в [response.json](response.json) и [model_output.md](model_output.md).
2. **Выводы модели**:
   - Модель дала однозначный ответ **«No»**: DeltaFuse проверяет исключительно сумму токенов переданных файлов и не валидирует полный prompt (системные инструкции, схемы инструментов, шаблон чата, резерв ответа).
   - Модель построила контрпример: файлы на 16,000 токенов + оверхед ~4,000 токенов = ~20,000 токенов, что вызывает context overflow / truncation на локальной модели.
   - Модель самостоятельно выделила погрешность эвристики `words * 1.3` на коде (независимо совпав с дефектом [F-003](../../findings/F-003.md)).
   - Модель указала на тихий пропуск ошибок чтения `read_text(..., errors="ignore")` и `except: pass` (независимо совпав с дефектом [F-004](../../findings/F-004.md)).
3. **Независимая верификация утверждений модели**:
   - Утверждение 1: `validate_context_budget` принимает только `context_budget` и `files` -> **Подтверждено** (`src/deltafuse/core/context.py:L125-128`).
   - Утверждение 2: `estimate_files_tokens` считает только `f.is_file()` -> **Подтверждено** (`src/deltafuse/core/context.py:L112-122`).
   - Утверждение 3: Системный промпт и оверхед не учитываются -> **Подтверждено** (в кодовой базе DeltaFuse нет вызова шаблонизатора перед проверкой бюджета).
   - Вывод модели является полностью достоверным и основан на фактической реализации.

## Ограничения

- Длительность инференса модели (421 с) обусловлена гибридным MoE оффлоадом на CPU/GPU и генерацией глубокой reasoning-фазы (1283 токена).

## Handoff

- **Результат**: Локальная LLM пригодна для решения задач архитектурного анализа контрактов, но требует высокого бюджета времени (до 7-10 мин на сложный аналитический промпт) и достаточного окна ответа (>= 2048 токенов).

# Запрос пользователя: Перенести Rate Limiter на новый сервер и обновить конфигурацию (S08c)

Операционное изменение: необходимо перенести сервис Rate Limiter с текущего сервера `limiter-prod-01` на новый `limiter-prod-02`:

1. Обновить конфигурацию деплоя: hostname, порт (с 8080 на 9090), путь к логам (`/var/log/ratelimiter/` → `/opt/logs/ratelimiter/`).
2. Обновить health check URL в мониторинге с `http://limiter-prod-01:8080/health` на `http://limiter-prod-02:9090/health`.
3. Обновить runbook `docs/ops/runbook.md` с новыми координатами сервиса.
4. Никаких изменений в коде, спецификациях или тестах не требуется.

Это чисто операционное изменение без влияния на функциональность продукта.

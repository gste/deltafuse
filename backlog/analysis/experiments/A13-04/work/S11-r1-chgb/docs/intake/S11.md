# Запрос пользователя: Статистика burst-окна (S11-B)

В сервисе Rate Limiter (`security.ratelimit`) нужна выборка статистики по ключу за текущее окно.

Требования:
1. Метод `get_window_stats(key)` обязан возвращать словарь с полями `accepted`, `rejected`, `remaining_tokens` для ключа.
2. Счётчики окна сбрасываются вместе с логикой пополнения токенов существующего limiter.
3. Вызов статистики не списывает токены и не меняет лимиты.
4. Для неизвестного ключа возвращать нулевые счётчики и текущий остаток по правилам инициализации ключа.

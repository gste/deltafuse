# LS-006 — Evidence только со штампом ядра

- **Дата:** 2026-09-11
- **Статус:** `planned`
- **Слой:** `evidence.py`, схема evidence, гейты targeting / implemented / converged
- **Зависимости:** нет. Можно параллельно с LS-001.

`deltafuse evidence` уже гоняет команду и пишет YAML. Гейт принимает любой валидный YAML: воркер может вписать `exit_code` и `behavioral-mismatch` руками. Skills говорят «не надо» — фронтир может.

## Зачем

Red/Green без прогона — поводок из честного слова. Ядро уже классифицирует failure; гейт должен требовать, что файл создал runner.

## Что сделать

- Штамп ядра в evidence (например `recorded_by: deltafuse-evidence` + hmac/hash содержимого прогона, или sidecar, который воркер не обязан имитировать осмысленно). Подделка «на глаз» должна падать на гейте.
- `check-gate` targeting/implemented/converged для code-route отвергает evidence без штампа.
- Docs/ops route не требует pytest-Red, но любой записанный evidence всё равно штампуется, если файл есть.
- Не ослаблять authentic Red (`behavioral-mismatch`).

## Не делать

- Заставлять воркера писать YAML evidence вручную «со штампом».
- Класть oracle/hidden suite в sandbox.

## Acceptance

Ручной `evidence/red/TASK-001.yaml` с правильной схемой, без штампа → targeting падает. Тот же путь после `deltafuse evidence --phase red …` → проходит. Регрессия: syntax-error по-прежнему не authentic Red.

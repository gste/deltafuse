# LS-002 — `deltafuse leash` по envelope

- **Дата:** 2026-09-11
- **Статус:** `done` — `deltafuse leash` сверяет git diff / `--file` с envelope; advisory → те же нарушения, exit 0
- **Слой:** `src/deltafuse/cli.py`, `src/deltafuse/core/` (новый модуль guard/leash)
- **Зависимости:** [LS-001](LS-001.md)

Гейт смотрит артефакты Change. Дифф рабочего дерева никто не сверяет с шагом. Воркер пишет `src/` на Intake — `check-gate intake` всё равно зелёный.

## Зачем

Ядро должно уметь сказать «этот diff вне поводка» без git hook и без хоста. Hook и CI (LS-004) только вызывают эту команду.

## Что сделать

- Команда `deltafuse leash [<product>]` (имя можно уточнить, не плодить синонимы): смотрит git diff (unstaged+staged относительно HEAD) и/или явный список путей.
- Сверяет с envelope текущего `next` selected. Нет selected и нет halt-only очереди — смотри LS-003 (эта карточка: только «есть ready step → diff ⊆ envelope»).
- Exit ≠ 0 при лишнем пути. `workflow.leash: advisory` — те же ошибки, exit 0.
- Не пишет продукт. Не вызывает LLM.

## Не делать

- Устанавливать hook (LS-004).
- Штамп evidence (LS-006).
- Парсить `docs/changes/**` в обход envelope.

## Acceptance

Синтетический продукт: selected=intake, файл `src/foo.py` в diff → leash падает. Тот же продукт, правка только `docs/changes/*/request.md` → проходит. Advisory не меняет обнаружение, меняет код выхода. Unit-тесты без живого LLM.

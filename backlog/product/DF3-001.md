# DF3-001 — V3 contracts и acceptance thresholds

- **Статус:** `done`
- **Зависимости:** нет

## Цель

До исправлений превратить принятые findings в воспроизводимые v3-тесты, закрепить границы доверия и определить абсолютные требования к качеству на 35B A3B при окне 32k.

## Работа

1. Добавить v3 decision records для transition authority, distribution и integrity profiles.
2. Описать v3 contract matrix: config, lock, Change, evidence, journals, receipts и adapters.
3. Добавить падающие тесты для F-01, F-02, SEC-01, SEC-02, F-03/F-04, B-01, B-04, SEC-03/04 и C-01.
4. Разделить тесты на accidental misuse и adversarial Worker.
5. Зафиксировать, какие проверки принадлежат Core, host и CI.
6. Добавить в канон Small-LLM Quality Contract: одна capability, один artifact layer и один outcome на Worker-вызов.
7. Зафиксировать 32k как полный qualification window, 16k/24 файла как default framework-controlled input budget и обязательный запас для host/tool/output.
8. До implementation-коммитов установить абсолютные численные v3 release thresholds для correctness, Process completion, retries, context peak, files loaded, hallucinated paths и envelope violations.
9. Для каждого threshold записать основание и способ измерения; значения выводятся из v3 quality contract и не подгоняются после qualification runs.
10. Зафиксировать единый v3 run manifest и формат per-run disk report, который использует DF3-009; последующее ослабление thresholds требует maintainer Decision.

## Acceptance

- Каждая принятая P0/P1 гипотеза имеет минимальный воспроизводящий тест или явно записанную причину переноса теста в зависимую карточку.
- Contracts не обещают защиту от полностью скомпрометированной OS.
- Никакая реализация не меняется в этой карточке.
- Целевая нижняя граница явно записана как 35B A3B / 32k, а более крупная или cloud LLM не является скрытой зависимостью.
- Для каждого release case определены абсолютные correctness/process/context thresholds, которые использует DF3-009.
- Карточка не запускает исторические сравнительные прогоны; все contracts, fixtures и acceptance criteria относятся только к v3.

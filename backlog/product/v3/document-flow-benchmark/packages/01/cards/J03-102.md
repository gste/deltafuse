## Changes and scope

The event schema defines closed Core, model-call, file-access, command,
compaction, boundary, and Human Gate variants over a closed common identity and
host-source envelope. EvidenceRef is independently closed and restricts keys to
relative forward-slash paths. Counts accept nonnegative integers or explicit
null where measurements can be unavailable, retaining the distinction between
zero and missing.

`decode_validate(kind, bytes)` accepts only two fixed local schema names,
rejects duplicate keys and nonfinite JSON during parsing, checks schemas before
use, refuses non-J03 external references, and validates with a prepopulated
in-memory resource registry. It never retrieves a schema over the network.

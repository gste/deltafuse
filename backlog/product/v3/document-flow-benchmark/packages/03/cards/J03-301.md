## Changes and scope

`oracle/variant-contract.json` freezes the generator contract: storyline
catalog (approve, reject-expert, supersede before/after partial,
registrar-early, registrar-reject, actor-reuse, duplicate-decision),
invalid-label taxonomy with expected public codes (late-decision →
`IGNORED_LATE_DECISION`, registrar-early → `EXPERT_REVIEW_INCOMPLETE`,
registrar-reject → `UNSUPPORTED_ACTION`, actor-reuse →
`ACTOR_ROLE_MISMATCH`, closed-route → `IDENTITY_MISMATCH`), duplicate and
crash bounds (commit-before-ack, publish-before-sent), topics, and the
frozen corpus (5 calibration seeds, 3 held-out seeds — never mixed, never
tuned).

`variants.py` derives each variant from nothing but the integer seed and
the contract: per-document storylines with seeded identities (actor pools
with distinct legal/security/registrar actors), a seeded cross-document
interleave preserving per-document causal order, duplicate deliveries
(at-least-once redeliveries, labeled), crash markers, and a guaranteed
deliberate invalid schedule per variant. Determinism holds because all
randomness flows through `random.Random` seeded with the seed string
(SHA-512-based seeding, independent of `PYTHONHASHSEED`), no `hash()` or
set iteration feeds output, values are integers and strings only, and the
stream serializes canonically with sorted keys. `build_manifest` emits the
J03-105 manifest shape (seed, generator source revision + own-source
SHA-256 + contract SHA-256, content-addressed operation stream with
evidence ref, ambiguity and workload ids) with the self-hash exclusion
policy of `canonical.py`.

The public inventory regeneration is recorded honestly: the J03-210

ran before the final `mvn clean`); with those artifacts since deleted the
installer tests correctly refused the stale entries. The regenerated

(178 entries) and the full suite passes against it.

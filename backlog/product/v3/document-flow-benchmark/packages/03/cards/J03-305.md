## Changes and scope

`SystemRunner` hashes and rejects link-bearing snapshots before execution,
creates a unique run/project identity, injects ephemeral credentials, builds
Java artifacts inside the snapshot, assembles and starts Compose services,
waits for health, preserves hashed command output and diagnostics, and removes
only that project's containers/networks/volumes. It distinguishes Worker Java
compilation failures (valid failed run, exit 1) from missing tools/images,
dropped readiness connections, and other infrastructure failures (exit 3).

Judge clients expose JSON HTTP, container-side Kafka consumption, and a strict
single-SELECT SQL observer. SQL is limited to named domain tables, denies
multiple statements, comments, mutating CTEs, dangerous functions, and DDL/DML,
and is additionally wrapped in a PostgreSQL read-only transaction under the
judge role. Fault control requires an acknowledged measured barrier and verifies
the exact `dev.deltafuse.run` container label before issuing `docker kill`.

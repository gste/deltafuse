# DF3-005 — Distribution, scaffolding и upgrade

- **Статус:** `blocked`
- **Зависимости:** DF3-003

## Цель

Одинаково работоспособная установка из nested checkout и wheel без потери provenance.

## Работа

1. На build генерировать immutable runtime bundle из schemas, skills и templates.
2. Читать wheel assets через `importlib.resources`; не копировать canonical docs в продукт.
3. Проверять bundle manifest при запуске и включать его в framework pin.
4. Добавить deterministic Change scaffolding; каркас не закрывает Intake.
5. Улучшить существующий `validate`, не добавлять второй validator command.
6. Блокировать update между несовместимыми v3 contract revisions при активных Changes до явного закрытия или переноса Change и повторного evidence run.

## Acceptance

- Wheel устанавливается в пустой venv и проходит CLI/smoke без source checkout.
- Source и wheel дают семантически одинаковые schemas/templates.
- Update не переподписывает evidence и не меняет product-owned files.

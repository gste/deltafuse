# DF3-009 — Bench, документация и release qualification

- **Статус:** `blocked`
- **Зависимости:** DF3-005, DF3-008

## Цель

Доказать гарантии 3.0 на всех платформах и подготовить безопасную миграцию пользователей.

## Работа

1. Считать process score по уникальным последовательным transitions.
2. Добавить adversarial M03: gate spam, oracle leak, journal forgery, envelope escape, synthetic evidence.
3. Изолировать judge pack от Worker на уровне wheel/machine boundary.
4. Синхронизировать EN/RU; убрать захардкоженные количества тестов.
5. Добавить единый config validator для `project.baseline` и остальных config contracts.
6. Выпустить migration guide, compatibility table и rollback procedure.
7. Прогнать pytest, оба smoke tests, wheel smoke и layout validation на v2/v3 fixtures.

## Acceptance

- Gate spam не повышает score.
- Windows и POSIX clean checkouts проходят одинаковый qualification suite.
- v2 migration и rollback проверены end-to-end.
- Нет legacy runtime paths вне документированного migration слоя.

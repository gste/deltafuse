# DF3-006 — Evidence и envelope authority

- **Статус:** `blocked`
- **Зависимости:** DF3-004

## Цель

Evidence доказывает проверяемое поведение, а task не может самовольно расширить область записи.

## Работа

1. Вычислять changed paths в Core из repository state; Worker list использовать только как expected subset.
2. Связать Red и Green одним task, test target и runner adapter.
3. Ввести project-owned test profiles для targeted и regression commands.
4. Разбирать структурированный результат runners; не доверять строковым маркерам как единственному oracle.
5. Ограничивать task paths capability catalog `code_roots`/`test_roots` и route contract.
6. Требовать принятую Scope Expansion Decision для выхода за capability roots.
7. Ограничивать и структурированно суммировать test output до передачи Worker; полный лог остаётся evidence artifact на диске.

## Acceptance

- `assert False`, `python -c pass`, пустой changed path и подмена команды не закрывают gate.
- Red/Green относятся к одному тестовому oracle.
- Task не расширяет envelope одной правкой frontmatter.
- Evidence retry возвращает минимальную причину и релевантные paths, а не загружает полный журнал или весь test suite в 32k context.

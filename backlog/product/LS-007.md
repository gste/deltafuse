# LS-007 — Контракт хоста: write envelope + Halt

- **Дата:** 2026-09-11
- **Статус:** `done`
- **Слой:** `docs/contracts/**` (leash + дополнение halt), skills/AGENTS
- **Зависимости:** [LS-001](LS-001.md), [HS-001](HS-001.md) (`done`)

HS-001 зафиксировал кнопки Halt. Хост всё ещё может дать модели ApplyPatch на любой файл и скормить `halt` текстом. Реализация кнопок — Cursor / fuse-map, не Core.

## Зачем

Поводок на git не ловит запись до commit. Хост, который режет tools по envelope, ловит раньше. Канон должен сказать MUST так же жёстко, как halt.

## Что сделать здесь

- В контракте leash (из LS-001) секция **Host MUST**: ограничить write-tools агента `envelope.write`; если `envelope` null и `leash: enforce` — не давать писать product globs (или только после Halt/inspect).
- Halt: не ослаблять; явно связать: при `halt.kind` decision|spec write envelope пустой для product code.
- Skills `/run`: если хост не умеет резать writes — всё равно звать `leash` перед концом шага (не замена hook).
- Явно: UI fuse-map и Cursor buttons **вне** `src/deltafuse/**`.

## Не делать

- Код плагина Cursor в этом репо.
- Рисовать доску в Core.
- Auto-accept.

## Acceptance

Контракт проверяется схемой envelope (LS-001) плюс документальный MUST для хоста. Тест на адаптеры: generated skills не учат писать `src/` на Intake. Нет требования, чтобы Cursor уже подчинялся — только канон, который fuse-map/хост могут запинить.

- **Дата:** 2026-09-09
- **Статус:** `planned` — отдельная ветка, не смешивать с A13
- **Слой:** CLI + Python API в этом репозитории; UI — соседний git root `../fuse-map`
- **Зависимости:** нет кода A13. Желателен зелёный контрактный pytest (A13-01), не блокер формулировки

**Контракт совместимости:** [docs/contracts/board-snapshot.md](../../docs/contracts/board-snapshot.md) + [board-snapshot.schema.yaml](../../docs/contracts/board-snapshot.schema.yaml) (`schema_version: 1`, обязателен `layout`). Пин потребителя: `../fuse-map/docs/contracts/`. Эта карточка — реализация транспорта.

## Зачем

Внешняя доска (рабочее имя **fuse-map**) полностью stateless: на запуск — пути product-репо, на выходе — проекция снимка. Колонки, шаги и карточки живут только в контракте. DeltaFuse тоже stateless: процесс подключается ссылкой/пинном. Сейчас нет команды снимка; UI иначе начнёт парсить `docs/changes/**` и хардкодить lifecycle.

## Три слоя (не смешивать SSOT)

| Слой | Где живёт | Что хранит |
|---|---|---|
| Product | git-репо продукта | Change YAML, spec, DEC, evidence |
| DeltaFuse | pin в `.deltafuse/lock.yaml` | гейты, skills, схемы; **без своей БД карточек** |
| fuse-map | соседний git `../fuse-map` | ничего: корни — аргументы запуска; доска — снимок |

## Минимум в DeltaFuse (эта карточка)

Read-only точка входа, например:

```text
deltafuse board <product-root> --json
```

тот же снимок — как функция в `src/deltafuse` (чтобы UI не шелл-парсил stderr).

Снимок должен валидироваться схемой контракта (`schema_version: 1`, не раздувать `change.yaml`):

- `layout.columns` + `layout.steps` — геометрия доски для pinned framework version, даже если `changes` пуст
- lock/config: framework version, `call_width`, `project.baseline`
- активные Changes: id, title, status, route, относительный path
- `blocked-on-decision` + id открытых `DEC-*` в `proposed`
- счётчики slices/tasks; флаги red/green на диске
- архив только с `--archive`
- корни из `.deltafuse/config.yaml` `paths.changes` / `paths.archive`, не хардкод
- каждый happy-path `status` ровно в одной колонке; терминалы — ни в одной

Нет lock → ошибка «не продукт DeltaFuse», не пустая доска-угадайка.

## Не делать

- Писать status, archive, «запустить skill», HTTP-демон, индекс-файл в продукте «для доски»
- Auto-accept DEC, hidden suite в UI, analog CLI / `re-verify`
- Класть Electron/веб в этот репозиторий
- Тащить тексты `docs/spec/**` / `request.md` в JSON доски

## Acceptance (когда ветка)

- На фикстуре с двумя Changes разных status JSON содержит обе карточки и полный `layout`
- Репо без `.deltafuse/lock.yaml` → ненулевой exit
- Вызов не создаёт и не меняет файлов в продукте
- Тест на схему снимка; `check-gate` на каждый CHG в board **не** обязателен (лениво / флаг)

# WA-001 — Агент-воркер с песочницей `next`

- **Дата:** 2026-09-10
- **Статус:** `planned` — `feature/2026-09-10-worker-agent`
- **Слой:** Worker `llm` (скрипт/модуль рядом с ядром, не внутри FSM)
- **Зависимости:** 2.3.0 (`next`, `coverage`, `check-gate`). Не WQ-001 / fuse-map.

A09/A13 скармливают ornith до 24 файлов и на Specify всё `docs/spec/**`. Ядро уже называет узкий `allowed_read` / `spec_refs`; вызывающий это игнорирует. Гейт не перехватывает живые чтения.

## Зачем

Без адаптера 2.3.0 не доезжает до модели. Цель не «Intake→Archive 11/11», а честно измерить, пишет ли ornith live spec, когда видит только шаг.

## Минимум (агент)

Цикл без выбора шага из промпта:

```text
deltafuse next --json
→ skill шага + файлы только из allowed_read
→ модель
→ запись только в allowed_write
→ coverage / check-gate только на pass close
```

- Инструменты: `list` / `read` / `write` / `done`. Read/write вне glob — отказ, без тела файла.
- Ядро не вызывает LLM. Нет HTTP в `deltafuse` CLI. Нет MCP.
- Human Gate (DEC / spec accept) — стоп, не auto-accept.
- Skills с `process/skills/**` текущей ветки. Extras A09 («только SLICE-01», «напиши ratelimit.md») не подставлять. Hidden/oracle не в промпт.

## Пилот (n=1)

SUT: `ornith-1.5-35b-a3b` Q4_K_M, `:1240`, `--reasoning off`. Studio `:1234` нет. Нет `:1240` → `blocked`, не облако.

Кейс **S05** (два capability / policy). Не полный A09.

1. Intake → Analyze: `next` режет `routing` → `SLICE-01` → `SLICE-02` → `coverage` (CLI).
2. Specify только первого среза (`specify_pass: slice`). Стоп.

| Исход | Что значит |
|---|---|
| На диске live spec-файл из `spec_refs` первого среза | рычаг работает; можно второй срез |
| Снова пустой spec-delta при узком `allowed_write` | потолок модели; агента не шлифовать |
| Один `SLICE-01` на две routing capability | агент не зовёт `next` / пишет мимо pass |

S01 в пилот не входит. Если S05 Specify живой — отдельным шагом контроль: пустой продукт по-прежнему не `specified`.

Не гонять Decompose/Declare/Implement/Verify в этом пилоте. Не патчить `backlog/analysis/experiments/A09-*/**`.

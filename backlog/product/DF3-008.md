# DF3-008 — Schema v3 и Declare migration

- **Статус:** `blocked`
- **Зависимости:** DF3-004, DF3-006, DF3-007

## Цель

Устранить legacy `targeting` vocabulary и перевести продукты на versioned v3 contracts.

## Работа

1. Выпустить schema v3 для Change, task, evidence, receipts, lock и board contracts.
2. Заменить v3 writes `targeting`/`target-confirmed` на Declare-aligned states.
3. Реализовать dry-run и apply migration с backup/manifest и идемпотентностью.
4. Поддержать v2 read только в ограниченном migration path.
5. Обновить skills, templates, adapters, validators и board layout атомарно.

## Acceptance

- После миграции legacy tokens отсутствуют в product artifacts.
- Повторный migration не меняет дерево.
- Неизвестная или частичная версия останавливается с точной диагностикой.

# DF3-008 — Schema v3 и Declare contracts

- **Статус:** `blocked`
- **Зависимости:** DF3-004, DF3-006, DF3-007

## Цель

Устранить legacy `targeting` vocabulary и выпустить согласованные versioned v3 contracts без runtime-совместимости с предыдущими версиями.

## Работа

1. Выпустить schema v3 для Change, task, evidence, receipts, lock и board contracts.
2. Заменить v3 writes `targeting`/`target-confirmed` на Declare-aligned states.
3. Добавить fail-closed диагностику для artifacts неизвестной версии или legacy vocabulary; Core не преобразует их автоматически.
4. Обновить skills, templates, adapters, validators и board layout атомарно.
5. Создавать новые Change artifacts только по schemas v3.

## Acceptance

- В новых v3 product artifacts отсутствуют legacy tokens.
- Artifacts предыдущих версий не читаются как валидные v3 и не изменяются автоматически.
- Неизвестная или частичная версия останавливается с точной диагностикой.

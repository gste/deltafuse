## Зачем

Pass `coverage` в AN-001 всё ещё просил модель написать YAML. Это третий жирный вызов Analyze и типичный schema-fail. Ядро может собрать каркас без прозы.

## Минимум

```text
deltafuse coverage <change-dir>
```

- Читает `request.md`, `routing.yaml`, `slices/*.md`
- Пишет только `coverage.yaml` (claim → slice, `spec_refs` среза, пустые `tasks`)
- Не вызывает LLM, не трогает spec, не auto-accept DEC
- Halt, если нет routing или какая-то routing capability без среза
- Повторный запуск сохраняет уже записанные `tasks` / `evidence` / `status`
- Неизвестные top-level ключи (в т.ч. `schema_version`) не валят схему `coverage`

Skill: при `analyze_pass: coverage` запустить `deltafuse coverage`, затем `check-gate --gate analyzed`. Не hand-write YAML.

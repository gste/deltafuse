# WK-004 — Human adapter (чеклист из контракта шага)

- **Дата:** 2026-09-10
- **Статус:** `done` — `deltafuse next --human` на `feature/2026-09-10-worker-kernel`
- **Слой:** CLI; текст из `STEP_CONTRACTS` + `PHASE_CONTRACTS`, не второй lifecycle
- **Зависимости:** [WK-003](WK-003.md). Человек заполняет те же файлы Change, что и `llm | script`

Скилл сегодня — промпт для модели. Человек не должен читать `SKILL.md` как закон. Ядро уже знает шаг, reads/writes и gate. Нужна инструкция из контракта: что открыть, что написать, чем закрыть.

## Зачем

Тот же I/O, что у воркера. Не «процесс для людей». DEC / spec / merge остаются Human Gates и в чеклисте явно: не auto-accept.

## Минимум

```text
deltafuse next --human
deltafuse next --human --step declare
deltafuse next --human --json
```

Чеклист выбранного ready:

- bound: change path, task path, skill, gate
- Read / Write из `PHASE_CONTRACTS` этого шага
- proof: `deltafuse evidence` для Declare/Implement (не руками YAML)
- close: `deltafuse check-gate <path> --gate <gate>`
- строка «те же файлы Change, не второй процесс»

Нет ready — чеклист blocked: открыть DEC/spec, не звать LLM, потом снова `next`. Exit 1.

Не писать `guide.md` в продукт. Не копировать прозу skills.

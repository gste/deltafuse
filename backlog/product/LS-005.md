# LS-005 — Human Gate пишет только `decide`

- **Дата:** 2026-09-11
- **Статус:** `planned`
- **Слой:** `decide.py`, FSM/`check-gate`, журнал ядра
- **Зависимости:** нет. Можно параллельно с LS-001.

Роли запрещают воркеру ставить `accepted` в DEC. Файлы это не запрещают: модель правит frontmatter, гейт видит `accepted` и едет дальше. `decide` — удобная кнопка, не единственный писатель.

## Зачем

Halt-контракт бессмыслен, если accept можно вписать в markdown.

## Что сделать

- Переход DEC `proposed` → `accepted`|`rejected` и spec `specification-proposed` → accepted/rejected **только** через `deltafuse decide`.
- Прямая правка файла: `check-gate` / `leash` / отдельная проверка целостности отказывает (штамп, журнал `.deltafuse/gate-journal.jsonl`, или сравнение с последним событием `decide`).
- Воркер по-прежнему пишет тело DEC в `proposed`. Нельзя писать `accepted` руками.
- Не auto-accept. Не merge.

## Не делать

- Блокировать Bootstrap DEC с `change: null` без отдельного `decide` (нужен тот же CLI, тот же журнал).
- Доверять чату «я принял».

## Acceptance

Синтетика: `status: accepted` в DEC без записи `decide` → analyzed/specified (где требуется accepted DEC) не закрывается. Тот же DEC после `deltafuse decide … --status accepted` → проходит. Тест, что Worker-скиллы по-прежнему не содержат инструкцию править status на accepted.

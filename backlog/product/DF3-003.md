# DF3-003 — CI leash и framework manifest

- **Статус:** `blocked`
- **Зависимости:** DF3-001

## Цель

Сделать pin и CI leash проверкой фактически исполняемого кода и реального commit range.

## Работа

1. Добавить leash input `--base`/`--head` с точными SHA и отдельной проверкой dirty/untracked paths.
2. Для GitHub PR использовать base/head SHA, для push — before/after; обеспечить нужную fetch depth.
3. Включить `src/deltafuse/**`, entrypoints и runtime assets в versioned framework manifest.
4. Синхронизировать Python, PowerShell и Bash hash implementations.
5. Проверить tampering, rename, delete, submodule и shallow checkout cases.

## Acceptance

- Чистый PR checkout с out-of-envelope commit падает в CI.
- Любое изменение Core меняет content hash.
- Один canonical manifest даёт одинаковый digest на Windows и POSIX.

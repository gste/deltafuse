## Implementation and explicit scope adjustments

1. `src/deltafuse/core/artifact_policy.py`:
   - Introduced `resolve_change_stage(product_root, change_id)` to dynamically read the live Change stage (`archived`, `halted`, `converged`, etc.) from disk (`change.yaml` or workspace status).
   - Enforced `_INACTIVE_STAGES = {"archived", "halted", "converged", "abandoned"}` checks in `create_authorization_context` and `validate_artifact_policy`.
   - Operations targeting an inactive Change fail with `ArtifactPolicyError` (`code="inactive_change_stage"`).

2. `src/deltafuse/core/artifact_lock.py`:
   - Updated `revalidate_authority` to normalize stage/actor/work_item strings case-insensitively.
   - Enforced strict fingerprint matching (`fp1 != fp2`), rejecting stale or modified contexts during publication revalidation under lock.

3. `src/deltafuse/core/artifacts.py`:
   - Updated `ArtifactService` publication flow to query `_get_live_auth_context()`.
   - Under `ProductMutationLock`, live stage is re-resolved from disk before commit. If the Change has been archived or halted since preparation, `revalidate_authority` rejects the mutation.

4. Test suite updates:
   - Added `test_aw30_reproduce_archived_change_and_stale_revalidation_failure` in `tests/integration/test_artifact_security.py`.
   - Added `test_aw30_cli_create_archived_change_rejected` in `tests/unit/test_artifact_cli.py`.
   - Expanded `test_validate_artifact_policy_inactive_stage` and `test_revalidate_authority_revoked_inactive_stage`.

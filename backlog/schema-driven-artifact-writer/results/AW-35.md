## Implementation and explicit scope adjustments

1. `scripts/evaluate_artifact_writer.py`:
   - Replaced substring-based text matching in `evaluate_independent_oracle` with strict frontmatter parsing (`strict_read_artifact`) and YAML parsing (`yaml.safe_load`).
   - Compare typed metadata fields (`id`, `change`, `kind`, `slice`, `title`, `context_budget`, `claims`) against independent corpus expectations.
   - Added pre- and post-operation filesystem snapshot comparison (`pre_files` vs `post_files`). If an operation is denied (`passed_op == False` or `expected_valid == False` or `expected_gate_block == True`), any unauthorized disk mutation sets `disk_mutated_on_denial = True`, causing `gate_block_correct = False` and `semantic_correct = False`.
   - Integrated actual Core gate evaluation (`deltafuse.core.fsm.check_gate`) for applicable gate stages (`decomposed` for tasks, `analyzed` for routing, `specified` for spec-delta), returning `gate_scope` and `gate_errors`.
   - Handled `paired_model` mode cleanly, reporting `external_model_status: unavailable_no_endpoint` and `acceptance_status: open_for_AW-20` without synthetic score substitution.

2. `tests/unit/test_artifact_writer_eval.py`:
   - Added `test_independent_oracle_rejects_invalid_task_substring_fixture` to verify that an invalid task fixture containing valid-looking substrings (`id: WRONG`, `kind: INVALID`, `slice: MISSING`) fails oracle evaluation (`semantic_correct = False`).
   - Added `test_independent_oracle_rejects_forbidden_disk_mutation_on_denied_op` to verify that forbidden disk mutation on a denied request fails oracle evaluation.
   - Added `test_independent_oracle_runs_core_gate_check` to verify `check_gate` integration.

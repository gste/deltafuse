## 1. Executive Summary

Card AW-09 implemented `src/deltafuse/core/artifact_transactions.py` and `process/artifact-operations/receipt.schema.yaml` along with unit tests in `tests/unit/test_artifact_recovery.py` and integration tests in `tests/integration/test_artifact_crash_recovery.py`. It provides transaction journal logging (`TransactionManager`), durable receipts compliant with `receipt.schema.yaml`, request ID idempotency checks (re-using identical request IDs while rejecting payload conflicts), deterministic receipt digest computation (`compute_receipt_digest`), and crash recovery (`recover_pending_transactions`) across prepared, published, and committed boundaries without overwriting or rolling back ambiguous third-party edits.

## 1. Executive Summary

Card AW-12 integrated Core execution evidence with support for the `--phase verification` phase, strict storage schema validation, stamp protection, and baseline revision binding across `src/deltafuse/core/evidence.py`, `src/deltafuse/cli.py`, `process/schemas/evidence.schema.yaml`, `tests/unit/test_evidence.py`, and `tests/integration/test_artifact_evidence.py`.

It enforces:
1. `verification` phase evidence execution: Requires `task=None` (or `task: null`), target file `evidence/verification/run.yaml`, and mandatory `base_revision`. Rejects non-null task arguments for verification with `EvidenceRunError`.
2. Storage schema validation: Validates evidence payloads against `process/schemas/evidence.schema.yaml` before stamping and writing YAML files.
3. Authenticity & Stamp Verification: Enforces `recorded_by: deltafuse-evidence` and kernel SHA256 stamp checks. Rejects manual stamp forgery or unauthorized runner scripts.
4. Retention of legacy rules: Preserves `red`, `green`, and `regression` phase requirements and task ID bindings.

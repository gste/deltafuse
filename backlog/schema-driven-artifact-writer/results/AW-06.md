## 1. Executive Summary

Card AW-06 implemented `src/deltafuse/core/artifact_policy.py`. It binds envelope, lock, schema, and source inputs to cryptographic authorization fingerprints (`AuthorizationContext`), prevents path traversal (`..`, Windows drive letters, alternate streams, reserved device names), blocks target paths escaping `product_root` via symlinks or reparse points, guards protected `.deltafuse` paths, and enforces strict privilege separation between generic Worker payloads and authenticated internal Core callers (preventing forged `actor="core"` requests).

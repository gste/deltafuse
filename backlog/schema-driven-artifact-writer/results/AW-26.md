## 1. Summary of Changes

Remediated Review Finding 6 where transaction journals and receipts were directly rewritten without atomic storage, Writer/Core lock roots differed or were bypassed, corrupt journal entries were silently skipped, and Core evidence writes bypassed shared mutation locking and atomic storage.

### Key Modifications:
- `src/deltafuse/core/artifact_transactions.py`:
  - Added `_write_atomic_json` helper using `atomic_create` and `atomic_replace` with same-filesystem staging and `fsync` flush for journal and receipt records.
  - Updated `find_transaction_by_request_id`, `prepare_transaction`, and `recover_pending_transactions` to detect corrupt/truncated journal JSON records or missing required fields (`transaction_id`, `state`, `request_id`) and fail closed with `ArtifactTransactionError` (code `corrupt_journal`) instead of silently skipping them.
- `src/deltafuse/core/artifacts.py`:
  - Wrapped `finalize_receipt` in `create` and `update` so post-publication receipt failures retain the transaction state as `published` in the journal and raise `ArtifactTransactionError` (code `receipt_finalization_failed`), preventing false success or claiming unchanged.
- `src/deltafuse/core/evidence.py`:
  - Updated `write_stamped_evidence` to accept `lock_timeout`, acquire `ProductMutationLock(product_root, timeout=lock_timeout)`, and write evidence YAML atomically using `atomic_create` / `atomic_replace`.
- `src/deltafuse/core/transitions.py`, `src/deltafuse/core/decide.py`, `src/deltafuse/core/scaffold.py`, `src/deltafuse/core/analyze.py`:
  - Standardized all Core file writes (`change.yaml`, task/slice markdown frontmatter status, `spec-delta.md`, decision files, `coverage.yaml`, request files) to use atomic storage primitives (`atomic_create` / `atomic_replace`) under `ProductMutationLock(product_root)`.
- `tests/integration/test_artifact_locking.py`:
  - Added `test_evidence_contends_on_product_mutation_lock` asserting that `write_stamped_evidence` contends on `ProductMutationLock`.
- `tests/integration/test_artifact_crash_recovery.py`:
  - Added `test_corrupt_journal_record_stops_recovery_failing_closed` verifying truncated journal records fail closed.
  - Added `test_receipt_failure_after_publish_preserves_journal_state_and_raises` verifying post-publish receipt failures preserve `published` state.

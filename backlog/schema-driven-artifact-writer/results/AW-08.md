## 1. Executive Summary

Card AW-08 implemented `src/deltafuse/core/artifact_lock.py` alongside unit tests in `tests/unit/test_artifact_concurrency.py` and integration tests in `tests/integration/test_artifact_locking.py`. It provides shared product-level mutation locking (`ProductMutationLock`) using OS-level file locking (`msvcrt` on Windows / `fcntl` on POSIX) and threading mutexes, safe liveness checks and dead-PID lock recovery (without blind age-based lock deletion), whole-file expected SHA256 target hash validation (`validate_expected_hash`), pre-commit authorization fingerprint recheck (`revalidate_authority`), and byte-for-byte no-op mutation detection (`check_noop_mutation`).

## 4. Platform Limitations & Scope Note

Product mutation locking and optimistic concurrency are implemented in `src/deltafuse/core/artifact_lock.py`. Raw uncoordinated external text editor writes outside DeltaFuse Core API bypass advisory locking; host-enforced write permissions or explicit hash check before commit are required for hostile writer exclusion. Transaction journal recovery and durable receipts will be implemented in card `AW-09`.

## 1. Summary of Changes

Remediated Review Finding 4 where a malformed `.deltafuse/lock.yaml` did not prevent artifact creation, receipt schema hashes were hardcoded to zero digests (`sha256:` + 64 zeros), and receipt timestamps were hardcoded to a fixed string (`2026-09-18T08:00:00Z`).

### Key Modifications:
- `src/deltafuse/core/artifact_registry.py`:
  - Added `verify_product_lock` and `find_product_lock` methods to fail closed on missing, unparseable, or invalid `.deltafuse/lock.yaml` product pins (including checking `lock_schema_version_errors` and `framework.version`/`framework.content_hash`).
  - Added methods `get_descriptor_hash`, `get_storage_schema_hash`, and `get_envelope_schema_hash` to compute SHA256 hashes directly from raw schema and descriptor file bytes, eliminating parsed-object hash substitution.
  - Removed current-working-directory fallbacks in schema/descriptor resolution.
- `src/deltafuse/core/artifact_transactions.py`:
  - Updated `prepare_transaction` to capture real ISO 8601 UTC timestamps once at preparation time and record actual `operation_schema_hash`, `storage_schema_hash`, `storage_schema_identity`, and performed/not-evaluated validation scopes (`envelope`, `input`, `schema`, `policy`, `reference`, `whole_gate`).
  - Updated `finalize_receipt` to reuse the preparation timestamp and actual byte schema hashes, and added `_validate_receipt_against_schema` to validate every generated receipt against `process/artifact-operations/receipt.schema.yaml` before persistence.
- `src/deltafuse/core/artifacts.py`:
  - Added `self.registry.verify_product_lock(self.product_root)` calls to `create` and `update` methods.
  - Passed exact descriptor and storage schema byte hashes to `prepare_transaction`.
- `tests/unit/test_artifact_service.py`:
  - Added Red reproduction test `test_reproduce_finding_4_malformed_lock_and_receipt_provenance`.
  - Updated `product_root` fixture to initialize a valid `.deltafuse/lock.yaml`.
- `tests/unit/test_artifact_cli.py` & `tests/integration/test_artifact_security.py`:
  - Updated test fixtures to supply valid `.deltafuse/lock.yaml` files.
